# SubBoost v1.0.3

## 中文

### 改进
- 优化订阅二维码预览的展示方式。
- 二维码悬浮预览调整为向上展开，避免被下方内容挤压。
- 增大二维码显示尺寸，提升移动设备扫码识别率。
- 强制二维码保持正方形比例，避免因布局压缩导致变形。
- 优化悬浮区域，使鼠标从“二维码”按钮移动到二维码预览时更加稳定，不易意外关闭。

### 说明
- 本版本主要优化管理后台二维码预览体验。
- 不涉及数据库迁移。
- 不影响现有订阅链接、下载、刷新、编辑、删除等功能。
- 可从 v1.0.2 直接升级。

---

## English

### Improvements
- Improved the subscription QR code preview experience.
- QR code previews now open upward to avoid being compressed by content below.
- Increased the QR code display size for easier scanning on mobile devices.
- Enforced a square aspect ratio to prevent layout-related distortion.
- Improved the hover interaction so the preview remains visible more reliably when moving the pointer from the QR button to the QR code.

### Notes
- This release focuses on improving the QR code preview in the dashboard.
- No database migration is required.
- Existing subscription link, download, refresh, edit, and delete features are unaffected.
- Users running v1.0.2 can upgrade directly.
