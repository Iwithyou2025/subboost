# SubBoost v1.0.4

## 中文

### 改进
- 优化订阅二维码预览弹层的位置。
- 二维码预览现在会更准确地显示在“二维码”按钮上方，减少视觉偏移。
- 改进悬浮预览的对齐方式，使二维码在不同布局宽度下保持更自然的位置。
- 保留现有向上展开、正方形显示和较大二维码尺寸。

### 说明
- 本版本主要优化管理后台二维码预览的视觉体验。
- 不涉及数据库迁移。
- 不影响现有订阅、下载、刷新、编辑、删除等功能。
- 可从 v1.0.3 直接升级。

---

## English

### Improvements
- Improved the positioning of the subscription QR code preview.
- The QR preview now aligns more naturally above the QR code button with less horizontal offset.
- Improved popup alignment behavior across different layout widths.
- Existing upward expansion, square QR display, and enlarged QR size are preserved.

### Notes
- This release focuses on improving the dashboard QR code preview experience.
- No database migration is required.
- Existing subscription, download, refresh, edit, and delete features are unaffected.
- Users running v1.0.3 can upgrade directly.
