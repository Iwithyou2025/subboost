# SubBoost v1.0.1

## 中文

### 新增

- 在订阅列表的“链接”按钮旁新增“二维码”功能。
- 鼠标悬停在“二维码”按钮上时，自动展示当前订阅链接的二维码。
- 二维码尺寸固定为 20mm × 20mm，方便移动端代理客户端扫码导入。

### 说明

- 本版本仅新增订阅二维码查看功能。
- 不涉及数据库迁移。
- 不影响原有订阅链接、下载、刷新、编辑、删除等功能。

## English

### Features

- Added a QR code action next to the subscription link button in the subscription list.
- The QR code is shown automatically when hovering over the QR code button.
- The QR code size is fixed at 20mm × 20mm for easier scanning by mobile proxy clients.

### Notes

- This release only adds the subscription QR code preview feature.
- No database migration is required.
- Existing subscription link, download, refresh, edit, and delete behavior remains unchanged.
